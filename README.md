# Dota Pulse

**Демо:** [https://rqik.github.io/DotaStats/](https://rqik.github.io/DotaStats/)

Dota Pulse — локальное SPA для прозрачной аналитики матчей Dota 2. Приложение показывает исходные данные, размер выборки, формулы и ограничения расчётов, а не обещает результат ставки.

## Возможности

- анализ форы по убийствам на реальных матчах OpenDota;
- отдельная оценка вероятности победы в матче;
- выбор выпуска турнира и команд, участвовавших в нём;
- фильтрация турниров по году в названии и уровню OpenDota;
- ручной анализ драфта и разбор завершённого матча по Match ID;
- журнал ставок, расчёт прибыли, ROI и просадки;
- локальное хранение данных в IndexedDB и импорт/экспорт.

Часть потоков ещё развивается. Если OpenDota не предоставляет необходимые данные, приложение показывает явное ограничение и не подменяет результат демонстрационными значениями.

## Технологии

React 18, TypeScript, Vite, React Router, Zustand, Recharts, Zod, Dexie и Vitest.

## Локальный запуск

Требуется актуальная LTS-версия Node.js.

```bash
npm ci
npm run dev
```

После запуска приложение доступно по адресу `http://localhost:4173/`.

## GitHub Pages

Workflow [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml) проверяет и собирает приложение при каждом push в `master`, после чего публикует каталог `dist` на GitHub Pages. Сборка использует базовый путь `/DotaStats/`, а копия `index.html` в `404.html` обеспечивает открытие внутренних SPA-маршрутов напрямую.

Перед первым деплоем в настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** как источник публикации. Деплой также можно запустить вручную через **Actions → Deploy to GitHub Pages → Run workflow**.

## Данные и ограничения

- данные матчей и команд загружаются из OpenDota;
- API-ключ необязателен и хранится только локально;
- точная дата турнира может отсутствовать, поэтому год определяется по названию выпуска;
- расчёты носят информационный характер и не являются рекомендацией сделать ставку.
